📘 String

Description

A String is a sequence of Unicode characters used to represent textual data. Strings are one of the most important data types in programming and are widely used in software development, web applications, data processing, and coding interviews. Python provides powerful built-in features to create, manipulate, search, format, and process strings efficiently.

Definition

A String is an ordered sequence of characters enclosed in single quotes, double quotes, or triple quotes. In Python, strings are immutable, meaning they cannot be modified after creation.

Python Example

text = "OpenAI"

print(text)
print(len(text))
print(text.upper())
print(text[::-1])

Characteristics

  • Ordered sequence of characters.
  • Immutable in Python.
  • Supports indexing and slicing.
  • Allows duplicate characters.
  • Supports Unicode.
  • Easy to traverse using loops.
  • Provides many built-in methods.
  • Widely used in DSA and real-world applications.

Operations

1. Create a String

text = "Hello World"\nprint(text)

2. Indexing

text = "Python"\nprint(text[0])\nprint(text[-1])

3. Slicing

text = "Programming"\nprint(text[0:6])\nprint(text[::-1])

4. Concatenation

a="Hello"\nb="Python"\nprint(a+" "+b)

5. Repetition

print("Hi "*3)

6. Length

text="OpenAI"\nprint(len(text))

7. Uppercase

print("python".upper())

8. Lowercase

print("PYTHON".lower())

9. Replace

print("Hello World".replace("World","Python"))

10. Split

print("Python Java C++".split())

11. Join

words=["Learn","Python"]\nprint(" ".join(words))

12. Strip

print("  Python  ".strip())

13. Find

print("Programming".find("gram"))

14. Count

print("banana".count("a"))

15. Membership

text="Python"\nprint("Py" in text)

16. Comparison

print("apple"=="apple")

17. Reverse

print("Python"[::-1])

18. String Formatting

name="Ankan"\nprint(f"Hello {name}")
